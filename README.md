# Пилатес-студия «Линия»

Концепт-сайт камерной студии пилатеса на реформерах (Красносельский район, Санкт-Петербург).
Учебный проект по дисциплине «Веб-аналитика» (Московский Политех): на сайте установлены счётчики LiveInternet, Sber Ads и MyTracker.

Сайт: https://riya-113.github.io/web-analytics-guide/

Страницы генерируются из `_src/build.py`. ID счётчиков:

```
TOP100_ID=1234567 TMR_ID=3456789 python3 _src/build.py
```
